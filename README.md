# lionsentry-react-front-end
Repository for LionSentry react front-end 

# setup

- **Pull down the repository**

```
    https://github.com/Curt-Landry-Ministries/lionsentry-react-front-end.git
```

- **node Version**: 18.19.0
- **npm Version**: 10.2.3

- **Keeper**: Log into [KeeperSecurity](https://keepersecurity.com/), create the file `src/util/firebase/firebaseConfigData.ts` and add the Keeper contents inside of the LionSentry Files vault.

```
    cd lionsentry-react-front-end
    npm i
    npm run start
```

## Accessing the App 🌐

- **Web Application**: Accessible at http://localhost:19006/

## Note

UI will be updated to new version.
